## 首次真实素材试验命令

以下为待执行示例。每次使用独立项目目录；抽帧率和分辨率按素材调整。

### 1. Mac 上传视频（服务器抽帧的备选路线）

```bash
scp /你的绝对路径/corner.mp4 gs-train:/data/projects/
```

### 2. 服务器抽帧、相机求解

```bash
mkdir -p /data/projects/corner/input
ffmpeg -i /data/projects/corner.mp4 -vf "fps=2,scale=1600:1600:force_original_aspect_ratio=decrease" -q:v 2 /data/projects/corner/input/frame_%05d.jpg
source /data/apps/activate-sugar.sh
python gaussian_splatting/convert.py -s /data/projects/corner --no_gpu
```

先筛除模糊照片再求解。确认照片能注册到同一个有效模型；转换脚本默认使用 `sparse/0`，若出现多个模型，先检查再训练。

### 3. 服务器训练并提取网格

```bash
tmux new -s corner
source /data/apps/activate-sugar.sh
python train_full_pipeline.py -s /data/projects/corner -r dn_consistency --low_poly True --refinement_time short --export_obj True --export_ply True
```

按 `Ctrl+B` 后按 `D` 脱离会话；之后用 `tmux attach -t corner` 返回。此为首轮低面数、短细化试验参数。

上游流水线通过 `os.system` 调用部分阶段，不能只凭总脚本退出码判断成功，需检查阶段日志、模型和贴图文件。

### 4. Mac 下载结果

在本地项目根目录执行，先确认服务器实际输出目录：

```bash
mkdir -p artifacts/corner
rsync -avP gs-train:/data/apps/SuGaR/output/ artifacts/corner/
```

此示例下载整个默认输出目录；有多个项目后应改为对应项目子目录。视频、照片、权重、网格与贴图通常较大，提交 Git 前应配置忽略规则。
