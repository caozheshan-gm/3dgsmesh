## 视觉检查与结论

在SuperSplat中载入两份基础高斯；自建模型另参考已经输出的6张测试视角渲染。KIRI默认视角可见沙发、桌子、门和柜子方向，比自建局部模型覆盖更广；同时可见明显模糊和拉伸。截图为`kiri-view.jpg`。自建已知视角渲染位于`artifacts/myroom-20261017/preview/test/renders/`。

这不是严格同相机画质测试：没有KIRI相机位姿，也未把两份模型配准。因此不能给出KIRI对原视频的PSNR，不能据不同默认视角判定所有局部清晰度优劣。

关键判断：

1. 同一素材KIRI恢复更广，证明不能将本次自建结果差主要归咎于拍摄。
2. 自建相机求解仅48/243张进入同一模型，这是已知的首要短板；需先改善抽帧、相机模型/参数和位姿求解，再评估高斯训练与网格方法。
3. KIRI文件不包含算法、使用帧数、注册率、训练迭代数，不能仅从PLY逆推出其完整内部流程。
4. SuGaR输出约213万个高斯主要来自网格每面绑定6个高斯；数量变大不代表覆盖恢复。
5. 只有KIRI高斯PLY，没有KIRI网格，不能比较两家的Mesh质量，也不能断言KIRI Mesh由这个PLY直接转换得到。

详细数值见`ply-statistics.json`、`background-analysis.json`。
