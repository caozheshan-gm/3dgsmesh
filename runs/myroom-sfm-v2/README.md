# myroom 相机求解优化

用户要求先恢复可靠整房，成功后才继续高斯/Mesh。原视频与首轮模型保留。

## 实验

1. 原243照片与缓存匹配：OPENCV→PINHOLE，最大48张，未改善。
2. 原视频12fps候选，长边2000（尺寸偶数），每0.25秒用缩略灰度Laplacian方差选择更清晰帧：1460→487张。PINHOLE初始焦距1600、主点562/1000，可优化焦距；SIFT上限16384，guided sequential，overlap30，4°初始化。
3. 备用：SuperPoint+LightGlue提供学习式对应，再经COLMAP几何验证与求解；尚未启动。

服务器目录：`/data/projects/myroom-sfm-v2/`。当前没有启动新的高斯或Mesh训练。

学习式匹配源码：官方 https://github.com/cvg/LightGlue ，提交`eb42fee2d71449efb0aa5c10549752b5d75384d8`。备用环境`/data/envs/sfm-lightglue`使用原Torch系统包，但kornia0.6.12、opencv-python-headless4.8.1.78独立安装，未改原训练环境。

学习式匹配已启动，使用同一487张选帧：SuperPoint(长边1280提特征，最多2048点，坐标映回2000输入)，LightGlue默认精度/自适应参数、flash=False，GPU实测预热后约0.02—0.04秒/样本对。配对为近邻1—12帧、多时间间隔及平均描述子检索12个远距离候选，全部经COLMAP几何验证。仅提对应与求解，不训练高斯。
